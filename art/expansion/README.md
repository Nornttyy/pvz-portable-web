# 沙盒原创角色扩展

在现有本体的沙盒里新增 10 种植物、10 种僵尸。原有 8 种植物保留，共 18 种原创植物、10 种原创僵尸。入口分别是植物 / 僵尸面板底部的“原创植物 / 原创僵尸”，不跳网站，不导入资源。

## 美术与尺寸

- 使用内置 image_gen，共 25 张源图；未调用外部生成 API。
- 完整提示词：`prompts-plants.json`、`prompts-units.json`、`prompts-hardware.json`、`prompts-vfx.json`。
- 原图：`generated/`；接入游戏的透明分件：`parts/`；原版画布及透明边界记录：`parts.json`。
- 84 个角色分件，骨骼部件匹配原版连接范围、保留原版画布；独立道具保留长宽比。没有把头、嘴、衣服、下巴、头盔合成一张晃动贴图。
- 机枪嘴、四个枪管及前沿分别替换；三线嘴部独立校准。缩略图按实际透明轮廓适配卡槽，不再整张画布直接拉伸。
- `atlas-proof.png` 是源图检查拼版；`rig-proof.png` 是读取真实 reanim 变换的离线姿态校验图，不是浏览器截图。

## 子弹、特效与位置修正

- `vfx-parts.json` 记录 40 个透明素材：8 种子弹、16 个命中帧、16 个技能帧；`vfx-proof.png` 为检查拼版。动画帧使用共同裁切范围，避免播放时中心跳动。
- 火、冰、电、小型、重炮、散射、追踪和腐化弹分别使用生成素材。原有 8 种属性植物也接入；火焰溅射和寒冰减速仍由原战斗逻辑处理。
- 发射位置读取当前嘴部骨骼矩阵，包含缩放、摆动与附件变换。三线分别使用下、中、上三颗头，保持对应行的飞行轨迹。
- 子弹绘图只使用一次场景平移；非对称尾巴围绕弹丸核心旋转，追踪弹可以向左回转。碰撞框、阴影随弹丸尺寸变化。
- 特效进入原生行排序，不再统一叠在整张地图之上；限制在游戏区域，暂停和清场同步处理。
- 泡泡糖单独附在嘴旁，保留下巴；助威僵尸卡片中的道具使用手部附件变换。小豌豆以叶片落地点缩放，阴影同步缩小。

`scripts/slice-vfx.swift` 仅切分和缩放生成位图，没有代码手绘替代素材。`SandboxVisualRules.h` 集中记录 800 × 600 原生画布下的绘制尺寸与核心位置。

## 验证与复现

`node --test tests/pages.test.mjs` 包含完整资源校验、WASM 初始化、字体修复及实际生产战斗模块的状态模拟。`tests/expansion-combat.cpp` 使用无渲染引擎替身执行生产模块，不等同于浏览器实测。

`tests/visual-coordinates.cpp` 执行生产绘制模块，捕获矩阵调用，检查嘴部锚点、三线三坐标、核心位置、反向追踪、按行绘制和暂停清理。它不是浏览器/GPU 实测；当前环境未连接浏览器，不能据此声称所有动态画面已通过人工验收。

资源包保留原有 2912 个非沙盒文件的逐字节内容，新增 / 更新仅发生在 `images/sandbox/`。原版存档与冒险植物定义不改写。

生成素材属于非官方同人扩展；原版美术与角色权利仍属于各自权利人，不随代码开源许可转移。
