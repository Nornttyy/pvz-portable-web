# 科技僵尸腿部骨骼审计

审计范围：原版普通僵尸 `Zombie.reanim` 的六条腿轨道，以及
`art/tech/generated/` 的十张科技僵尸分件图集。此文档只记录审计结果；
没有修改运行时代码、原图集或现有导出文件。

## 原版六条轨道与原生尺寸

`Zombie.reanim` 的第一帧明确绑定了以下六个 PNG。尺寸是 PNG 的原生画布，
不是内容的 alpha 包围盒。原版这些帧均以 `sx=sy=0.800` 绘制，因此右列也列出
未改骨骼时的名义屏幕尺寸。`inner` / `outer` 是前后景深层，不是“左腿 / 右腿”。

## 建议的标准 runtime 导出规格

若保持原版 `Zombie.reanim` 的枢轴、第一帧 `0.8x` 缩放和运行时代码不变，
每个科技僵尸都应提供以下六张**真正独立**、透明的图，而不是两张整腿：

| 目标分件 | 标准原生画布 | 说明 |
| --- | ---: | --- |
| `inner-upper` | 15 x 26 | 膝盖处必须是透明切口 |
| `inner-lower` | 32 x 36 | 膝、踝两端都应独立 |
| `inner-foot` | 27 x 17 | 只含脚/鞋，不带小腿 |
| `outer-upper` | 21 x 39 | 膝盖处必须是透明切口 |
| `outer-lower` | 24 x 30 | 膝、踝两端都应独立 |
| `outer-foot` | 42 x 21 | 只含脚/鞋，不带小腿 |

为避免改坏原骨骼：新画件应保留上述画布尺寸和原始关节方向；透明边缘可以
保留，但不要把整条腿缩进同一张大画布后交给单一轨道。现有 `leg-left` /
`leg-right` 命名也不能替代 `inner` / `outer` 的三段式轨道。

## 结论

十套图集目前都没有可以 alpha-only 裁成原版六条腿轨道的资产，因此不应把
现有整腿强行切成三段，也不应直接把 128–316 px 高的整腿塞进原版 15–42 px
的轨道画布。所有十个角色都需要按照上表重绘六个独立腿部件；其中五个拥有
整腿参考图的角色可以沿用其配色、鞋型和机械装置设计，但关节附近必须重新画
出透明分离边界。
