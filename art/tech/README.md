# 科技花园素材生产规范

这是一套全新的科技花园阵营，不是旧原创卡的换色或拼贴。它服务于“根网共振”：`菌缆菇`把相邻科技植物连成网，充满三格能量后由玩家手动触发；干扰天线会压制充能，拖缆钩手会拉断连线，修植苔能修复。

## 视觉边界

- 画面为低分辨率手绘卡通战略游戏感：不规则墨线、3–5 档平涂明暗、轻微纸感笔触、鲜亮但克制的青绿／琥珀／青蓝／紫电色组；**不做写实金属、3D 渲染、硬表面照片纹理或霓虹 UI 图标**。
- 角色可以参考原版战场的比例、朝向和动画节奏，但每个轮廓、五官、装置和配色都须为新绘；不得复用、描摹或仅改色现有角色 PNG。
- 植物的科技感来自“活体植物长出有机装置”：叶脉像线路、菌丝像软电缆、晶体像种荚；避免把普通炮嘴硬贴在脑袋上。僵尸则是破旧园艺／回收设备与僵尸身体自然结合。

## 交付规则

- 每个条目须交付透明 RGBA PNG 的独立骨骼件，正常态、受损一／二级，以及在 `production-spec.json` 写明的专属子弹和特效。所有件以同一基准地面线和原生骨骼锚点导出，不能把头、嘴、手臂、腿或特效烤进一张大图。
- 植物发射口必须是单独前景件；头部与嘴／喉／孔的连接处要留 2–4 px 重叠安全区，关闭和张开时均不得露出背景、穿帮或悬空。没有嘴的单位也要把“发射孔／工具端”拆成可摆动前景件。
- 僵尸至少拆为头、下颚、身体、内外上／下臂、手、装备前景；涡轮、钩索、磁铁、天线等会动的物件另拆。护盾或背包不能遮住嘴、手或死亡掉落层。
- 每个可受击角色至少有 `normal`、`damage1`、`damage2` 三个清晰阶段：裂纹／凋蔫／冒烟应沿本体结构发展，不可只套半透明黑层。带护甲单位另有 `armor`、`armor-damage1`、`armor-damage2` 和掉落件。
- 命名使用 `art/tech/<slug>/<part>-<state>.png`；图层从后到前为：背景附肢 → 身体 → 头／脸 → 嘴或工具端 → 前臂／装备 → 前景火花／弹道。输出前以 1×、1.5×、2×格子验证轮廓、炮口、脚线与碰撞中心。

## 验收

1. 卡牌缩略图中十种植物／十种僵尸可仅凭剪影区分。
2. 每个发射物从独立锚点出现，首帧不盖住嘴、下一帧不跳位。
3. 头部、嘴、手、腿在待机、攻击、受击、死亡四种姿势下均无断层。
4. 根网、干扰、断缆、修复、三格共振均有可读的战场特效，且特效不遮挡格子点击。
5. `production-spec.json` 中所有 `parts`、`damage`、`projectiles`、`vfx` 均有真实成品后才可打包；禁止用临时色块、旧卡图或未透明化整张概念图代替。
