# 僵尸行为重做（原生身份，冒险与沙盒共用）

本轮调整七种已有僵尸，不增加独立沙盒卡槽、不改原关卡出场顺序。其余已改版僵尸（急眼铁桶、续杯撑杆、读手机、倒车小鬼）的机制保留。红温豌豆保留 100% 音效系数及 300 怒气／3 秒 50 发；按后续要求，将同一段声音比上一版再提高两个半音，保持三秒时长。

| 僵尸 | 本轮变化 | 可见动作与应对 |
| --- | --- | --- |
| 摸鱼僵尸 | 原走六秒歇两秒，改为真正躺平，倒下的一刻绊倒近处同路普通步行者一秒 | 整套原骨骼绕脚倒下再起身；仍能被攻击，无额外伤害，不持续锁人 |
| 碰瓷路障 | 保留破帽后三秒装死，倒下的一刻可绊倒同伴 | 帽子破损与原倒地动作保留，巨人／车辆不受影响 |
| 催更旗手 | 删除 50% 隐形加速光环，每六秒让同路最近的身后步行者向前蹦约 105 像素 | 旗手停下催促，同伴整身前跳 0.6 秒；植物挡住跳跃，不越墙 |
| 抢镜铁门 | 删除隔空分摊伤害，每六秒移动到前方同路同伴身前 | 0.45 秒举门前倾抢位，直射子弹实际打中门；门碎就停止抢位 |
| 刹不住橄榄球 | 删除 1.8 倍周期加速，改为周期性滑铲刹车，撞到同伴会绊倒 | 伸腿后仰、向前滑 0.7 秒、倒地一秒后爬起；不伤害同伴，不滑过植物 |
| 搭便车气球 | 删除凭空生成新僵尸，改为搬运场上已有的一名步行者，每只气球只成功搬运一次 | 0.3 秒拉起、短暂牵引、0.45 秒落地；原身份／血量／盔甲不变，吹飞或打破气球会放下原乘客 |
| 插队梯子 | 保留寻找植物较少邻路的规则，取消瞬间换路 | 0.45 秒侧身挤过去，路程中点切换命中行；只走相邻陆地，不跨水路 |

## 素材与存档

没有新生成整身图：原骨骼、头、手脚、盔甲及破损阶段沿用原资源。只对原部件作连接一致的动作变换；气球牵引线是两像素的简单线条。没有增加战场说明字幕。

1030–1035 是新的有界交互阶段。计时、起点、目标路、乘客指向的气球代际 ID、一次性搬运标记都使用原生已序列化字段，不改变存档布局，也不使用裸指针或原生关联僵尸链。阶段标签区分 `mTargetPlantID` 存放的植物 ID（大嘴花含住）和僵尸 ID（气球牵引）；分别从对应容器查找。

冻结停止对应动作计时；暂停停止全部推进；魅惑、死亡、气球破裂／吹飞／越界均有退出路径。被牵引僵尸冻结或裹黄油时停止牵引，落地阶段在解冻后继续。无新增掉落、回血、额外伤害。

验证：实际生产 C++ 边界测试、原生 WASM 浏览器操作、原植物互动回归及冒险原生选卡回归。测试脚本见 `scripts/qa-zombie-behaviors.mjs`。
