# 抽象角色：原版骨骼、小幅改动

本批保留原版低分辨率、偏灰配色、描边、阴影和骨骼。坚果不再分嘴、露牙：完整原脸和两级破损贴图随整株向前顶一下，然后弹回原格。该动作直接调整原生绘制变换，没有新绘制坚果贴图。

豌豆吐射手复用原版反向豌豆骨骼及豌豆弹丸；射手整体飞出再返回。读手机僵尸复用报纸僵尸身体、胳膊、行走和暴走动作，只替换手持道具及其损坏状态。

## 唯一生成部件

使用 **imagegen 技能的内置图片生成工具**，不是 CLI，生成一张带真正透明通道的横持手机。参考原版报纸的透视和低饱和画风，不生成文字、人物或手部。

- 原生骨骼尺寸成品：[phone-native-v1.png](phone-native-v1.png)，86 × 82，透明边距保留握持位置。
- 完整实际提示词：[phone-prompt.txt](phone-prompt.txt)
- 注册脚本：`scripts/register-abstract-phone.swift`，只裁切、缩放和转成 ARGB 像素，不重绘生成图。

不在卡面叠加中文简称，不在侧栏常驻角色列表，也不在每次种植时弹出名字。保留费用；名称沿用原版悬停/图鉴方式显示。沙盒抽象卡使用与原版一致的五列卡片网格。

## 套娃与碰瓷

- 套娃土豆直接使用原版土豆的埋地、出土、闪灯、爆炸粒子与音效。三层分别为原大小、80%、60%，脚底锚点不变；前两次爆炸后重新准备6秒，不回血。替换冒险1-6解锁的土豆地雷，费用75。
- 碰瓷路障沿用原版路障的完整、破损、掉落贴图。路障被打掉后整套骨骼绕脚底倾倒，停止行走和啃咬三秒，然后平滑起身；仍可受伤。倒地计时使用原生存档字段，不新增悬浮说明文字。
- 此批没有生成或替换位图，画面变化由已有角色的整体变换和原生动画实现。
